# 📌 The Labyrinth

---

Gioco di ruolo a turni in Java con interfaccia grafica JavaFX.
Il giocatore sceglie nome e classe del suo eroe (Cavaliere o Mago) e attraversa un dungeon di 3 livelli scegliendo ogni volta tra tre porte, che possono nascondere nemici, scrigni o fontane, fino alla battaglia finale contro un boss.
La partita si può salvare e riprendere.

---

## 🚀 Come eseguire il progetto

---

Prerequisiti

- Java 25 (LTS)
- Gradle

## Istruzioni

<aside>

git clone https://github.com/MicheleAntolini/RPG129230.git

cd RPG129230

</aside>

## Build del progetto

<aside>

gradle build

</aside>

## Esecuzione

<aside>

gradle run

</aside>

## **🤖 Uso di strumenti di AI**

---

Nella realizzazione del progetto è stato utilizzato **Claude** (Anthropic), tramite claude.ai.
L'ideazione del gioco, le regole e le meccaniche sono mie. L'AI è stata usata come
**tutor personale**, **assistente alla programmazione** e **supporto** per queste attività:

- Progettazione:
    - consigli per rispettare i principi SOLID e su come applicarli al meglio
    (ad esempio le interfacce “RandomSource” e  “GameRepository”)
- Assistente alla programmazione:
    - revisione del codice e individuazione dei bug, per verificare che ogni parte funzionasse correttamente
- Interfaccia grafica:
    - supporto nell'uso di JavaFX e SceneBuilder (collegamento tra file FXML e controller)
    - foglio di stile CSS realizzato a partire dalla mia descrizione dello stile
- Bilanciamento:
    - simulazioni di molte partite per bilanciare le statistiche dei personaggi e il combattimento
- Documentazione:
    - stesura dei commenti Javadoc
